## 🌟 Key Features

- **Same-to-Same Visual Alignment:** Precision replication of Elementor Kit #7 design system (Pitch Black `#000000`, Industrial Bronze `#B27638`, Soft Blue `#EAEEFD`, Google Fonts `Poppins` & `Roboto`).
- **100% Vector Icons:** Built with Font Awesome 6 (`fa-solid`, `fa-brands`), zero emojis.
- **Dynamic Hero Section:** Center-aligned, buttonless, left & right navigation arrows, auto-calculating viewport height (`calc(100vh - headerHeight)`).
- **Overlapping Value Pillars:** Positioned over the hero fold (`margin-top: -140px`) with visible icons and titles.
- **Client Marquee:** Infinite auto-scrolling marquee placed below the About section querying corporate clients.
- **Stats Counter:** Prominent statistics showcase placed before the final Call-to-Action banner.
- **Minimal Project Lightbox:** Clean `820px × 520px` uniform image canvas with intuitive left/right navigation and subtle `1/4` image counter.
- **Custom Post Types (CPTs):**
  1. `hero` (Homepage Carousel Slides)
  2. `service` (Pre-Engineered Building Core Offerings)
  3. `project` (Complete & Ongoing Projects)
  4. `product` (Industrial Steel Raw Materials & Supplies)
  5. `project-review` (Corporate Client Logos for Marquee)
- **Taxonomies:**
  - `project-status` (`completed-projects`, `ongoing-projects`)
  - `project-category-` (`factory`, `warehouse`, `infrastructure`, `commercial`, etc.)
- **Dedicated Admin Options Pages:**
  - `Steel Villa > Contact Information`: Manage phones, official email, address, WhatsApp, and Google Maps embed.
  - `Steel Villa > Theme Settings`: Manage company tagline, footer corporate bio, stats counter values, sister company links, and copyright text.
- **Template-Specific Dynamic Meta Boxes:** Custom fields appear automatically in `wp-admin > Pages` based on the selected Page Template.
- **Built-in Demo Seeder:** Automatically populates all 5 hero slides, 6 services, 21 projects, 19 products, 12 marquee clients, and 10 FAQs upon theme activation!
- **Native GitHub Auto-Updates:** Connects directly to `https://github.com/shahriarnayem/steelvilla-theme` for one-click in-dashboard updates and automatic background updates.

## 🚀 Installation & Direct Upload

1. Download the latest `steelvilla-theme.zip` from GitHub Releases.
2. In your WordPress Admin Dashboard, navigate to **Appearance > Themes > Add New > Upload Theme**.
3. Choose `steelvilla-theme.zip` and click **Install Now**.
4. Click **Activate**. All demo content, CPTs, taxonomies, and initial option values will seed automatically!

---

## 🔄 How Updates Work

### Manual Update ("I ask for update"):
When a new version is released on GitHub:
1. Go to **Dashboard > Updates** or **Appearance > Themes**.
2. WordPress displays: *"There is a new version of Steel Villa available."*
3. Click **Update Now** to update the theme in-place with zero data loss.

### Automatic Background Updates:
1. In **Appearance > Themes**, click on **Steel Villa**.
2. Click **Enable auto-updates**.
3. When you push a new release to GitHub, WordPress will update the theme automatically in the background.
